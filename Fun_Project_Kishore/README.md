# Hand Cricket Game (Python)

## Description
This is a console-based Hand Cricket game developed using Python. 
The game allows a user to play against the system with toss, batting, bowling, and scoring features.

## Features
- Toss system (Head/Tail)
- Choice to Bat or Bowl
- Random system moves
- Score tracking
- Target-based second innings
- Final match result (Win/Loss/Tie)
- Replay option

## How the Game Works
1. User selects Head or Tail for toss
2. Winner chooses to bat or Bowl
3. The first innings is played
4. Target is set for second innings
5. Second innings continues until:
   - Player gets out OR
   - Target is achieved
6. Final result is displayed

## Technologies Used
- Python
- Random module
